# Space Invasion

A Python game project scaffold for a space-themed arcade game.

## Project structure

- `assets/`
  - `images/`
  - `sounds/`
  - `music/`
  - `fonts/`
  - `animations/`
- `src/`
  - `entities/`
  - `scenes/`
  - `ui/`
  - `managers/`
  - `utils/`
- `data/`
- `main.py`
- `settings.py`
- `requirements.txt`
- `README.md`

## Getting started

1. Create a virtual environment:
   ```bash
   python -m venv venv
   ```
2. Activate it:
   - Windows:
     ```powershell
     .\venv\Scripts\Activate.ps1
     ```
   - macOS/Linux:
     ```bash
     source venv/bin/activate
     ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the game:
   ```bash
   python main.py
   ```
